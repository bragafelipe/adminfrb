# Documentação do projeto

Este diretório concentra a documentação arquitetural e funcional do dashboard administrativo genérico.

## Arquivos sugeridos

- `overview.md`: visão geral do produto
- `architecture.md`: arquitetura do sistema
- `configuration.md`: formatos de configuração JSON/YAML
- `page-templates.md`: tipos de páginas reutilizáveis
- `menu-and-routing.md`: navegação e roteamento dinâmico
- `backend-contracts.md`: contratos entre backend e frontend
- `roadmap.md`: plano de evolução do projeto
